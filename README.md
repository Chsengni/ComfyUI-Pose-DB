# ComfyUI-Pose-DB

ComfyUI 自定义节点：内置 1439 张无脸人偶姿势参考图，在节点面板里勾选，**每勾选一张就多一个 IMAGE 输出**。

## 特性

- **整批输出**：固定的 `images` 输出，一次给出全部选中图（按勾选顺序拼成一个 batch），可直接接 SaveImage / ControlNet / 批量处理。
- **勾选即增输出**：另外每选一张就多一个 `img1 … imgN` 输出槽，顺序与勾选顺序一致，最多 32 个。
- **跟随 ComfyUI 主题**：面板与节点缩略图条读取 ComfyUI 自身的 CSS 变量，浅色 / 深色主题切换时自动变色。
- **内置图库**：1439 张（4 个系列 × 5 个角度 × 288 个姿势），300×400 JPG，整包约 22 MB，无需外部下载。
- **中文界面**：姿势名、分类、系列、角度全部为中文。
- **面板分批加载**：打开面板与滚动时按每批 150 张渲染，不会一次性铺满 1439 张。
- **节点内预览**：节点底部直接显示当前所选缩略图。

## 安装

把整个 `ComfyUI-Pose-DB` 目录放进 ComfyUI 的自定义节点目录，重启 ComfyUI，然后在节点菜单里搜索 **PoseDB**（分类 `PoseDB`）。

前端扩展由 ComfyUI 按目录名自动挂载，改目录名或使用软链都不影响。

## 使用

1. 添加节点 **PoseDB 姿势图选择器**。
2. 点节点上的 **「选择姿势图…」** 按钮打开图库面板。
3. 顶部 4 个圆角按钮切换系列（再点一次取消，回到全部），或用分类下拉 / 搜索框筛选；向下滚动自动加载更多。
4. 每个姿势是一张卡片：标题下 5 个角度小图，**点小图即勾选 / 取消**，同时把它切成卡片主图；同一张卡片内可以勾多个角度。
5. 点 **确定**：`images` 输出整批选中图，节点再长出 `img1 … imgN`、底部出现所选缩略图。
6. `images` 接 SaveImage / ControlNet 批量节点；单张用 `img1`、`img2`… 接 PreviewImage / KSampler 等任意 IMAGE 输入。

> 选了图却一张都读不出来时（例如 `web/thumbs` 没拷全），节点会直接报错并列出清单路径与失败原因，**不会**再静默输出 8×8 黑图。

再次打开面板可以增删；点「清空」后节点回到 1 个占位输出。

## 输出约定

| 项 | 说明 |
| --- | --- |
| 输出槽 0 | `images`：全部选中图按勾选顺序拼成的 batch，形状 `[N, 400, 300, 3]`，可接 SaveImage / 批量节点 |
| 输出槽 1..32 | `img1`、`img2` … 与勾选顺序一一对应 |
| 数据类型 | `IMAGE`，float32，范围 0~1，单张形状 `[1, 400, 300, 3]` |
| 尺寸不一致 | 若图库中混入不同尺寸的图，`images` 会按最大尺寸等比插值对齐后再拼接 |
| 未使用槽位 | 返回 8×8 黑色占位张量，不会被下游消费，不影响出图 |
| 全部读取失败 | 直接抛错（附清单路径 / 图片目录 / 失败原因），不再静默输出黑图 |
| 超过 32 张 | 只取前 32 张，面板会提示 |

## 主题

面板与节点底部的缩略图条读取 ComfyUI 自己的 CSS 变量（`--comfy-menu-bg`、`--comfy-input-bg`、`--border-color`、`--fg-color`、`--descrip-text`、`--p-primary-color` 等），取不到时按当前明暗主题使用兜底色。切换 ComfyUI 的浅色 / 深色主题时，已打开的面板会立刻跟着变。

## 图库面板

- **卡片分组**：288 个姿势各一张卡片，卡片内按顺序放 5 个角度（正面 / 俯视 / 仰视 / 侧面 / 斜侧），只有「单人全身・性感系 P018」是 4 个角度。
- **点小图 = 勾选**：小图上显示勾选序号徽标，卡片主图跟着切到最后点的那张；同一张卡片内可以勾多个角度，点主图也能切换当前主图的勾选。
- **筛选会缓存**：系列 / 分类的选择记在节点 properties 里，重开面板自动恢复上次选中的分类。
- 每批渲染 24 张卡片（约 120 张图），滚动到底自动加载下一批。
- 切换筛选或搜索会重置列表并回到顶部。
- `Esc` 关闭（分类下拉展开时先收起下拉），`Ctrl/Cmd + Enter` 等同于点「确定」。

## 内存占用

单张张量 300×400×3×4B ≈ 1.4 MB，勾满 32 张约 **46 MB**。节点内部有 32 张的 LRU 缓存，重复运行不会反复解码。

## 目录结构

```
ComfyUI-Pose-DB/
├─ __init__.py            节点注册入口（WEB_DIRECTORY = ./web）
├─ nodes.py               读图 → IMAGE 张量，带 LRU 缓存
├─ web/
│  ├─ pose_db.js          图库面板 + 动态输出槽 + 节点缩略图
│  ├─ catalog.json        图库清单（1439 条：id / 编号 / 名称 / 分类 / 系列 / 角度 / 路径）
│  ├─ thumbs/             300×400 缩略图 ×1439，后端输出与卡片主图共用
│  └─ small/              180×240 面板小图 ×1439，卡片里的 5 个角度按钮用它
└─ README.md
```

## 换图库

替换 `web/thumbs` 里的图片并更新 `web/catalog.json`，字段为 `id`、`no`、`name`、`cat`、`series`、`angle`、`thumb`，其中 `thumb` 是相对 `web` 的路径（如 `thumbs/xxx.jpg`）。重启 ComfyUI 后生效——清单在进程内缓存。
