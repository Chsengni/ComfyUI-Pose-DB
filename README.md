# ComfyUI-Pose-DB

ComfyUI 自定义节点：内置 **4345 张**角色参考图——1439 张姿势、1407 套服装穿搭、1499 张人像发型，在面板里挑图，直接输出 IMAGE；另有「角色合成」节点，把人像 + 服装 + 姿势拼成三张参考图和一整段中文提示词。

## 四个节点

| 节点 | 作用 | 输出 | 所在文件 |
| --- | --- | --- | --- |
| **PoseDB 姿势图选择器** | 1439 张姿势图，多选 | `images` 整批 + `img1…img32` | `nodes.py` + `web/pose_db.js`（原有节点，未改动） |
| **PoseDB 服装选择器** | 1407 套服装穿搭，多选 | `images` 整批 + `img1…img32` | `nodes_gallery.py` + `web/pose_db_gallery.js` |
| **PoseDB 人像选择器** | 1499 张人像 / 发型，多选 | `images` 整批 + `img1…img32` | `nodes_gallery.py` + `web/pose_db_gallery.js` |
| **PoseDB 角色合成** | 人像 + 服装 + 姿势各选一张 | `头部` `服装` `姿势` `提示词` | `nodes_gallery.py` + `web/pose_db_gallery.js` |

> 新增的三个节点全部写在独立文件里，`nodes.py` 与 `web/pose_db.js` 一行没动；即使扩展模块加载失败，原来的姿势图选择器也照常可用。

## 特性

- **整批输出**：固定的 `images` 输出，一次给出全部选中图（按勾选顺序拼成一个 batch），可直接接 SaveImage / ControlNet / 批量处理。
- **勾选即增输出**：另外每选一张就多一个 `img1 … imgN` 输出槽，顺序与勾选顺序一致，最多 32 个。
- **三合一角色配方**：人像 / 服装 / 姿势各选一张，输出三张参考图 + 拼好的中文提示词，提示词模板可自定义。
- **跟随 ComfyUI 主题**：面板与节点缩略图条读取 ComfyUI 自身的 CSS 变量，浅色 / 深色主题切换时自动变色。
- **中文界面**：姿势名、服装名称与标签、人像发型、分类、系列、角度全部为中文。
- **面板分批加载**：姿势每批 24 张卡片，服装 / 人像每批 60 块，滚动到底自动续加载。
- **节点内预览**：选择器底部显示所选缩略图，角色合成节点显示人像 / 服装 / 姿势三格预览。

## 内置图库

| 图库 | 数量 | 尺寸 | 分类维度 | 体积 |
| --- | --- | --- | --- | --- |
| 姿势 | 1439 | 300×400 JPG（面板小图 180×240） | 4 系列 × 5 角度 × 288 姿势 | 39 MB |
| 服装 | 1407 | 360×540 WebP | 8 分类（春夏秋冬 / 内衣睡衣 / 性感 / 泳装度假 / 派对礼服） | 14 MB |
| 人像 | 1499 | 400×500 WebP | 2 分区（正脸参考 / 造型氛围）× 4 发长 | 31 MB |

全部随节点包内置，无需联网下载。

## 安装

把整个 `ComfyUI-Pose-DB` 目录放进 ComfyUI 的自定义节点目录，重启 ComfyUI，然后在节点菜单里搜索 **PoseDB**（分类 `PoseDB`）。

前端扩展由 ComfyUI 按目录名自动挂载，改目录名或使用软链都不影响。

## 使用：选择器节点

1. 添加 **PoseDB 姿势图选择器** / **服装选择器** / **人像选择器**。
2. 点节点上的按钮（如「选择姿势图…」）打开面板。
3. 顶部圆角按钮切换筛选维度（姿势是 4 个系列，服装是 8 个分类，人像是 2 个分区），再点一次取消回到全部；人像还可按发长下拉过滤；搜索框支持中文名、编号、id、标签、英文关键词。
4. 姿势按「一个姿势一张卡片」展示：标题下 5 个角度小图，**点小图即勾选 / 取消**，同时把它切成卡片主图；同一张卡片内可勾多个角度。服装 / 人像点图块即勾选。
5. 点 **确定**：`images` 输出整批选中图，节点再长出 `img1 … imgN`、底部出现所选缩略图。
6. `images` 接 SaveImage / ControlNet 批量节点；单张用 `img1`、`img2`… 接 PreviewImage / KSampler 等任意 IMAGE 输入。

> 选了图却一张都读不出来时（例如 `web/` 目录没拷全），节点会直接报错并列出清单路径与失败原因，**不会**再静默输出 8×8 黑图。

## 使用：角色合成节点

1. 添加 **PoseDB 角色合成（人像+服装+姿势）**。
2. 点 **「选择角色配方…」**，面板有三个标签页：人像 / 服装 / 姿势，每个图库选一张（再点一次同一张 = 取消）。
3. 点 **确定**，节点输出：

| 输出 | 内容 |
| --- | --- |
| `头部` | 选中的人像参考图 |
| `服装` | 选中的服装参考图 |
| `姿势` | 选中的姿势参考图 |
| `提示词` | 拼好的中文提示词（STRING），可直接接 CLIPTextEncode / 文本节点 |

4. `style` 输入框填风格补充词（默认「写实摄影风格，柔和自然光，浅景深，高清细节」），会替换模板里的 `{style}`。
5. `template` 留空用内置模板；填了则用你的模板，支持占位符：

```
{portrait_name} {portrait_hair} {portrait_section}
{outfit_name} {outfit_cat} {outfit_kw} {outfit_tags}
{pose_name} {pose_angle} {pose_cat} {pose_series}
{style}
```

内置模板输出示例：

```
以图 1 的人物为角色原型，保留其面部特征与发型；穿上图 2 的整套服装；按照图 3 的姿势与镜头角度绘制。

【角色】短发・标准款（发长：短发）
【服装】象牙白荷叶边针织衫・牛仔迷你半身裙・大衣・短袜・白色运动鞋
【姿势】S 形站姿・胯部侧顶（视角：正面）
【风格】写实摄影风格，柔和自然光，浅景深，高清细节

要求：
- 面部特征、发型与图 1 完全一致
- 服装的款式、颜色、材质与图 2 完全一致
- 身体比例、四肢位置、镜头角度与图 3 一致
- 单人全身像，干净背景，柔和自然光，高清细节，无文字无水印
```

## 输出约定（选择器节点）

| 项 | 说明 |
| --- | --- |
| 输出槽 0 | `images`：全部选中图按勾选顺序拼成的 batch，形状 `[N, H, W, 3]`，可接 SaveImage / 批量节点 |
| 输出槽 1..32 | `img1`、`img2` … 与勾选顺序一一对应 |
| 数据类型 | `IMAGE`，float32，范围 0~1 |
| 尺寸不一致 | 不同尺寸混选时，`images` 会按最大尺寸插值对齐后再拼接 |
| 未使用槽位 | 返回 8×8 黑色占位张量，不会被下游消费，不影响出图 |
| 全部读取失败 | 直接抛错（附清单路径 / 图片目录 / 失败原因），不再静默输出黑图 |
| 超过 32 张 | 只取前 32 张，面板会提示 |

## 主题

面板与节点底部的缩略图区读取 ComfyUI 自己的 CSS 变量（`--comfy-menu-bg`、`--comfy-input-bg`、`--border-color`、`--fg-color`、`--descrip-text`、`--p-primary-color` 等），取不到时按当前明暗主题使用兜底色。切换 ComfyUI 的浅色 / 深色主题时，已打开的面板会立刻跟着变。

## 图库面板

- **标签页**：角色合成节点顶部有 人像 / 服装 / 姿势 三个标签，标签上的蓝色数字是该图库已选数量。
- **卡片分组**：姿势 288 个姿势各一张卡片，卡片内按顺序放 5 个角度（正面 / 俯视 / 仰视 / 侧面 / 斜侧），只有「单人全身・性感系 P018」是 4 个角度。
- **筛选会缓存**：每个图库的筛选条件记在节点 properties 里，重开面板自动恢复。
- 每批渲染 24 张姿势卡片 / 60 个服装人像图块，滚动到底自动加载下一批。
- 切换筛选或搜索会重置列表并回到顶部。
- `Esc` 关闭（分类下拉展开时先收起下拉），`Ctrl/Cmd + Enter` 等同于点「确定」。

## 内存占用

单张 300×400×3×4B ≈ 1.4 MB，姿势勾满 32 张约 **46 MB**；服装 / 人像尺寸更大（360×540 / 400×500），勾满 32 张约 66~77 MB。节点内部有 64 张的 LRU 缓存，重复运行不会反复解码。

## 换图库

- 姿势：替换 `web/thumbs` 与 `web/small` 的图片并更新 `web/catalog.json`，字段为 `id`、`no`、`name`、`cat`、`series`、`angle`、`thumb`。
- 服装 / 人像：替换 `web/costume/thumbs`（或 `web/portrait/thumbs`）并更新对应 `catalog.json`，字段见 `nodes_gallery.py` 里 `LIBS` 与面板读取的 `name / cat / tags / kw` 与 `name / section / hair / style`。
- `thumb` 是相对 `web` 的路径（如 `costume/thumbs/SPR-0001.webp`）。重启 ComfyUI 后生效——清单在进程内缓存。
